Desafio Markdown

Este é um desafio para praticar a formatação de texto usando Markdown. Abaixo estão algumas instruções e exemplos de como utilizar diferentes elementos do Markdown.

Instruções

  • Crie um arquivo README.md.
  • Adicione títulos, listas, links e imagens usando a sintaxe Markdown.
  • Salve o arquivo e visualize-o em um visualizador de Markdown.

Exemplos de Markdown

Títulos

Use o símbolo "#" para criar títulos. Quanto mais "#" você usar, menor será o título.

# Título 1
## Título 2
### Título 3

Resumo do projeto

  • Praticamos a formatação Markdown no README, com etapas e registro das alterações.
  • Usamos o GitHub para colaborar e conhecer commits, issues e pull requests.
  • Criamos esta página HTML com instruções, exemplos de títulos e um link para o repositório.
  • Estilizamos a página com CSS responsivo e adicionamos uma interação simples com JavaScript.
